## Current target

One clean schema-5 Python/Tkinter/SQLite application with mandatory real-project
ownership replaces the multi-version development implementation. Historical formats,
legacy task_timer, candidate bridges/adapters, compatibility inspection, backup/private
recovery and old qualification infrastructure are retired from the current target.
They remain available in Git history, not as executable acceptance obligations.

  Unassigned destination in Main/Archived/Move/Apply/Timesheet.
